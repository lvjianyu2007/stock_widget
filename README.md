# 自选股监控小组件（StockWidget）

Windows 桌面股票/基金监控小组件。Python + PySide6，行情走 **akshare（主）** 与 **pytdx（备）** 两条独立通道，主通道失败自动切备用。

无边框半透明窗口，可拖拽、可缩放，字号/配色/透明度全部可调；「面板 0% + 字体 100%」就是一组数字飘在桌面上。

---

## 功能

- **小组件形态**：无边框 + 圆角 + 柔和投影，左键按住任意位置拖动；四边、四角均可缩放，鼠标移到边缘自动变成对应指针；右下角有把手提示
- **样式全可调**：字号、文字颜色、上涨色、下跌色、背景色、**背景不透明度 0–100%**、**字体不透明度 0–100%**
- **实时预览**：设置面板顶部就是效果预览，改颜色/字号/透明度立刻能看见
- **自选股**：股票与 ETF/LOF 基金可以混着填；名称自动获取并缓存，长名字按列宽省略（悬停看全名）
- **涨跌配色**：红涨、绿跌、白平（三项颜色都能在设置里单独改）；价格与涨跌幅用涨跌平色，名称用文字色；代码在数据源里查不到显示 `-- / 无数据`，与真正的 `停牌` 区分开
- **双通道容错**：akshare 内部还会在多个接口间自动降级；pytdx 会在 100+ 台行情服务器里轮换，坏主机进冷却名单，用通的那台记进配置
- **状态可见**：底部显示当前实际生效的通道与更新时间（如 `akshare·新浪分钟 · 13:05 更新`）；取数失败时直接把原因显示出来，完整报错在悬浮提示里
- **休盘不空转**：午间休盘、收盘后、周末、节假日只取一次数据就停手（底部显示 `已收盘 · 15:00:05 数据`），开盘自动恢复；休盘中右键「立即刷新」可手动再取一次
- **本地暂存**：行情 10 秒快照与分钟线写入 `data/quote.db`（SQLite），**只保留当天**，每天首次启动自动清理旧数据；落盘失败不影响取数
- **当天实时分时**：列表每行的迷你分时缩略图（可关），点击即弹出该只的独立分时图窗口（价格线 + 均价线 + 昨收基准线 + 价格/时间刻度，无边框可拖动可缩放）
- **配置持久化**：窗口位置、尺寸、样式、自选股、名称缓存、可用行情服务器全部存到 `config.json`，下次启动原样恢复

## 快速开始（源码运行）

```powershell
git clone git@github.com:lvjianyu2007/stock_widget.git
cd stock_widget
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

> 没配 SSH 就用 HTTPS：`git clone https://github.com/lvjianyu2007/stock_widget.git`

依赖：`PySide6>=6.6`、`akshare>=1.12`、`pytdx>=1.72`（打包另需 `pyinstaller`）。

## 打包成 exe

双击 **`build.bat`** 即可（改完代码随时再点一次）。也可以用命令行指定模式：

```powershell
.\.venv\Scripts\python.exe build.py            # 目录版（推荐，启动快）
.\.venv\Scripts\python.exe build.py onefile    # 单文件版
.\.venv\Scripts\python.exe build.py both       # 两个都打
.\.venv\Scripts\python.exe build.py dir --no-clean   # 保留 build/ 缓存，打得更快
.\.venv\Scripts\python.exe build.py dir --no-open    # 结束后不自动打开 dist
```

| 产物 | 说明 |
|---|---|
| `dist\StockWidget\StockWidget.exe` | 目录版，启动快；整个 `dist\StockWidget` 文件夹可整体拷走 |
| `dist\StockWidget.exe` | 单文件版，约 95 MB（启动要解包，慢几秒） |

`build.py` 相比手敲 PyInstaller 命令多做这几件事（都是实际踩过的坑）：

1. **先结束正在运行的 StockWidget** —— exe 被占用时打包会莫名失败
2. **备份并还原 `dist` 里的 `config.json`** —— 重新打包不会丢掉你在 exe 里调好的样式、自选股、窗口位置
3. **清理旧产物**：删不掉（被占用/权限不足）就自动改名让开，保证打包继续；结束时会提醒哪些旧目录可以删
4. **校验产物真的生成了**，失败时直接把 `build_log.txt` 的末尾几行打到屏幕上
5. 缺 PyInstaller 时自动 `pip install`；结束后打印产物路径/体积/时间，并打开 `dist` 目录

打包注意事项（`build.spec` 里都已处理）：

- akshare / pytdx / curl_cffi / **py_mini_racer** 都有运行时才 import 的子模块，必须 `collect_all`；**缺 `py_mini_racer` 会让 exe 里所有新浪股票接口失效**（只在取数时报错，很难发现）
- `curl_cffi` 的原生 `libcurl-impersonate-*.dll` 在 `site-packages\curl_cffi.libs\`（包目录之外），靠 `os.add_dll_directory` 查找，必须放到 `_internal\curl_cffi.libs\`
- `config.json` 存放位置在打包后会切到 **exe 同目录**，否则每次启动样式和位置都会丢
- 未签名 exe 可能被 Windows「应用程序控制 / Smart App Control」拦一次，再点一次或给 `dist` 目录放行即可

## 数据通道

### akshare 通道（按"请求数少的优先"自动降级）

关键原则：**尽量别用整份快照**。新浪的全市场快照一次要发 70 个请求，10 秒刷新一轮的话一小时就是两万多次，很容易被限流——表现就是"又取不到数据了"。所以默认走"一只一个请求"的逐只接口。

| 顺序 | 后端 | 接口 | 特点 |
|---|---|---|---|
| 1 | 新浪分钟 | `stock_zh_a_minute`（1 分钟 K，只取最近几天） | **1 请求/只**，盘中也有当天数据，约 0.5s/只 —— 当前默认路线 |
| 2 | 新浪日线 | `stock_zh_a_daily`（只取最近十几天） | 1 请求/只，约 0.2s/只，但当天 K 线要**收盘后**才更新 |
| 3 | 东财盘口 | `stock_bid_ask_em` | 1 请求/只，不带名称；东财时好时坏（秒断时几乎不耗时） |
| 4 | 新浪快照 | `stock_zh_a_spot` | 70 请求，但**自带股票名称**，用于补名字 |
| 5 | 东财快照 | `stock_zh_a_spot_em` | 兜底，最慢 |

- **默认路线**：名称齐全时按上表 1→5 试，命中即止。实测一轮 **1.4–2.8 秒、3~4 个请求**（旧方案是 12 秒、71 个请求）
- **名称缺失**（比如刚加了新代码）→ 先走自带名称的快照补齐，**下一轮自动切回轻量路线**
- **逐只补齐**：一轮里每个后端只请求"还没拿到的代码"，缺哪只补哪只；单轮总时长上界 45 秒
- **冷却**：某条轻量通道一只都没取到（例如分钟线被限流），5 分钟内不再优先它，交给后面的通道
- **查不到的代码不拖后腿**：整市场快照也找不到的代码会被记为"未知"，之后不再为它去拉慢通道（逐只线路仍会每轮试着取）；单轮也不会为个别代码去跑东财快照，避免一轮被拖到 80 秒以上
- 自选股里含 ETF/LOF（`5xxxxx`、`15/16/18xxxx`）时，额外取基金行情（新浪 ETF → 新浪 LOF → 东财），整份都是基金时连 A 股快照都不拉

### 交易时段与休盘

交易时段按 **09:15–11:30、13:00–15:00**（含集合竞价）判断；交易日历取自 `ak.tool_trade_date_hist_sina`（一次请求、缓存复用，取不到就退化成"只按周末判断"）。

| 市场状态 | 行为 |
|---|---|
| 交易中 | 按刷新间隔正常取数 |
| 午间休盘 | **只取一次**，之后不再发请求，每分钟看一眼是否开盘 |
| 已收盘 / 未开盘 | 同上；底部显示 `已收盘 · 15:00:05 数据` |
| 周末休市 / 节假日休市 | 同上（节假日靠交易日历识别） |
| 休盘中取数失败（网络抖动） | 每 60 秒再试，最多 3 次，避免整个休盘时段没数据 |
| 休盘中手动刷新（右键 → 立即刷新）或改设置 | 强制再取一次 |

休盘期间不发任何行情请求，所以长时间挂着也不会被限流；开盘后自动恢复按间隔刷新。

15:00 收盘那一刻同理：状态从「交易中」切到「已收盘」时会补取一次，拿到的就是收盘价，随后安静下来。

### pytdx 通道（备用）

直连通达信行情服务器（TCP），不返回股票名称（名称由 `names` 缓存提供）。内置 100+ 台服务器轮换：**以"真的返回行情"判定可用**，连不上或返回空的进 10 分钟冷却名单，单轮扫描有时间上界，用通的那台写入 `tdx_host` 供下次直连。

### 底部状态怎么看

- `● akshare·新浪日线` —— 走的哪条后端；`⚠` 表示当前是备用通道，括号里会写主通道失败原因
- `取数中…` —— 正在请求（新浪快照那类要十几秒）
- `取数失败：…` —— 橙色文字，悬停看完整报错

常见报错含义：`接口返回的是网页而不是数据（多半被限流/拦截了）`、`连接被对方断开（多半被反爬拦截了）`、`没有匹配到任何代码`。

> 提示：新浪快照一次要发 70 个请求，刷新间隔设得太小（如 5 秒）很容易被限流；建议 **20–30 秒**。

## 文件结构

```
stock_widget/
├── main.py              # 入口：窗口、交互、右键菜单、取数线程、分时窗口接入
├── chart.py             # 分时图：坐标映射与配色 + 行内缩略图 + 独立窗口
├── panel.py             # 面板外观：几何常量与圆角/投影绘制（主窗口与分时窗口共用）
├── intraday.py          # 分时序列装配：分钟线记录 → 当天分时点（纯转换，可单测）
├── store.py             # 本地暂存：SQLite 落盘（10 秒快照 + 分钟线），只保留当天
├── datasource.py        # 行情通道：akshare 多后端降级 + pytdx 主备与容错
├── settings_dialog.py   # 设置面板（含实时预览）
├── config.py            # 配置读写、默认值、共享常量
├── tests/               # unittest 用例（store / intraday / datasource / chart）
├── docs/                # 任务文档：分时图设计稿与实现计划
├── requirements.txt
├── build.py             # 一键打包脚本（备份配置、清理旧产物、校验结果）
├── build.spec           # PyInstaller 配置（目录版 / 单文件版）
├── build.bat            # 双击打包（薄壳，实际调 build.py）
├── build_log.txt        # 最近一次打包日志（自动生成）
├── build/               # PyInstaller 中间产物（自动生成，可随时删）
├── dist/                # 打包输出（要的就是这里）
├── data/quote.db        # 运行时生成的本地行情库（自动生成，只留当天）
└── config.json          # 运行时生成
```

### v0.10.0 — 2026-10-15

- **新增四个模块**，把「取数 / 落盘 / 组装 / 绘制」分层，主窗口只留交互：
  - `store.py`：SQLite 落盘（`tick` 10 秒快照 + `minute` 分钟线），取数线程与 UI 线程各持一个连接（WAL 模式读写互不阻塞）；`close()` 会逐一收回**所有线程**的连接——Windows 上不收回会让 `data` 目录一直被占用
  - `intraday.py`：分钟线原始记录 → 当天分时序列的**纯转换**（不碰网络、不碰数据库，可直接单测）
  - `chart.py`：`IntradayPainter`（坐标映射与配色）+ `SparklineWidget`（行内缩略图）+ `IntradayChartWindow`（独立窗口）
  - `panel.py`：面板几何常量与圆角/投影/把手绘制，主窗口与分时窗口共用（纯搬移，外观与交互行为不变）
- **两个取数节奏**：行情仍按 `refresh_seconds`（默认 10 秒）走，分钟线**每 60 秒**拉一次；休盘时段在状态刚切换时补一次，收盘那一刻拿到的就是全天分钟线。分钟线只走 akshare——pytdx 不提供分钟线
- **分时图两种呈现**：列表行内 72×22 的迷你缩略图（点一下弹独立窗口），以及无边框、可拖动、右下角可缩放、可置顶的独立窗口（价格线 + 均价线 + 昨收基准线 + 右侧价格刻度 + 底部时间刻度）
- **均价线算法**：逐分钟累计成交额 ÷ 累计成交量；单分钟成交量为 0 时沿用累计均价正常连线，源头完全不提供成交量（累计量为 0）时该点跳过不画
- **只有行情、还没有分钟线时**（冷启动第一秒、分钟线接口失败、当天无成交）图上画单个点而不是一片空白
- **分钟线落盘 + 启动还原**：重启后分时图立刻就有当天已有点位，不必等下一次分钟线
- **修复 `_sina_symbol` 指数前缀**：`sh000001` / `sz399001` 这类自带前缀的指数此前会被重复拼前缀（`szsh000001`），导致指数取数失败
- **新增配置项 `show_sparkline`**（默认 `true`）：关掉后列表回归纯文字，分时图仍可右键菜单打开

## 已知限制

1. **北交所代码**（`4xxxxx / 8xxxxx / 920xxx`）新浪日线不支持；新浪 A 股快照也不含北交所，这类代码当前会显示「无数据」
2. **东财接口不稳定**：实测同一网络下东财会间歇性直接断开连接，程序会自动降级到新浪；若三条都失败则显示失败原因
3. **新浪会限流**：短时间高频刷新（尤其走快照路线时）可能触发，表现为"接口返回的是网页而不是数据"，间隔建议 ≥20 秒
4. **未签名 exe** 可能被 Windows 应用程序控制策略拦截首次运行
5. 债券、可转债等品种按股票规则显示（2 位小数）
6. **分时线形状是分钟级**：10 秒快照只用于原始留档与拼接「正在走的尾巴」，线的精细度取决于 1 分钟 K 线
7. **只保留当天数据**：跨日清理后不能回看昨天（表结构已含 `day` 字段，后续扩展历史回看不需要改表）
